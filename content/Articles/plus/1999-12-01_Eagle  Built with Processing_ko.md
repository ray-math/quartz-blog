> 이 작품은 Processing이라는 프로그래밍 환경을 사용하여 제작되었습니다. Processing은 2001년 MIT 미디어 랩에서 벤 프라이(Ben Fry)와 케이시 레아스(Casey Reas)가 개발한 오픈소스 프로그래밍 언어이자 통합 개발 환경입니다. 원래는 비프로그래머인 예술가와 디자이너에게 프로그래밍을 가르치기 위한 도구로 시작되었으나, 현재는 시각 예술, 데이터 시각화, 생성 예술(generative art), 인터랙티브 미디어 제작을 위한 강력한 플랫폼으로 자리잡았습니다. Processing은 Java 기반으로 작동하며, 복잡한 수학적 패턴, 알고리즘, 시뮬레이션을 비교적 간단한 코드로 시각화할 수 있다는 점에서 수학과 예술의 교차점을 탐구하는 데 이상적인 도구입니다. 특히 재귀 알고리즘, 프랙탈 구조, 입자 시스템, 물리 시뮬레이션 등 수학적 개념을 실시간으로 구현하고 상호작용할 수 있게 해줍니다.

> 이 "독수리(Eagle)" 작품은 Plus Magazine의 아카이브에 포함된 역사적 콘텐츠로, 1999년으로 날짜가 표시되어 있지만 실제로는 Processing이 개발된 2000년대 초반 이후에 제작되었을 것입니다. 당시에는 웹 브라우저에서 Java 애플릿(Java Applet)을 직접 실행할 수 있었기 때문에, Processing으로 제작된 인터랙티브 작품들을 웹상에서 바로 감상할 수 있었습니다. 그러나 보안 문제와 기술 발전으로 인해 현대의 웹 브라우저들은 더 이상 Java 애플릿을 지원하지 않습니다. 이는 디지털 아트와 교육 콘텐츠의 보존이라는 측면에서 흥미로운 도전 과제를 제시합니다. 많은 초기 디지털 수학 시각화 작품들이 기술적 플랫폼의 변화로 인해 접근 불가능하게 되었으며, 이를 현대적 웹 기술(JavaScript, WebGL 등)로 마이그레이션하거나 에뮬레이션하는 작업이 진행되고 있습니다.

> Processing 기반 작품들이 수학적으로 흥미로운 이유는 코드 자체가 수학적 사고를 직접적으로 반영하기 때문입니다. 예를 들어, 독수리와 같은 자연 형태를 표현할 때도 단순히 이미지를 불러오는 것이 아니라, 베지어 곡선(Bézier curves), 삼각함수를 이용한 날개짓 애니메이션, 입자 시스템을 통한 깃털 표현 등 수학적 함수와 알고리즘의 조합으로 형태를 생성합니다. 이러한 접근 방식은 "수학적 모델링을 통한 자연 현상의 재현"이라는 응용수학의 핵심 철학을 체현합니다. 또한 파라미터를 조정하여 실시간으로 형태를 변화시킬 수 있다는 점에서, 수학적 변수와 결과물 사이의 관계를 직관적으로 탐구할 수 있는 교육적 가치를 지닙니다. 생성 예술(generative art)의 맥락에서 볼 때, 이는 결정론적 규칙에서 출현하는 복잡성(emergence)이라는 수학과 컴퓨터 과학의 중요한 개념을 예술적으로 구현한 사례입니다.
