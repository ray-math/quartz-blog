# 박쥐 : Processing으로 구현한 생성 예술

이 콘텐츠를 보려면 java.com에서 Java를 설치해야 합니다.

> Processing은 2001년 MIT 미디어 랩에서 개발된 프로그래밍 언어이자 통합 개발 환경(IDE)으로, 시각 예술가들이 코딩을 배우고 프로그래머들이 시각적으로 생각할 수 있도록 설계되었습니다. Java를 기반으로 하며, 복잡한 설정 없이 간단한 코드로 그래픽, 애니메이션, 인터랙티브 작품을 만들 수 있습니다. 수학적 함수를 시각화하거나 알고리즘 아트(algorithmic art)를 제작하는 데 특히 적합하며, 교육 현장에서도 널리 사용됩니다. 이 작품의 경우, 박쥐의 날개 움직임을 삼각함수와 파라메트릭 방정식으로 모델링하고, 실시간으로 렌더링하여 생물학적 움직임의 수학적 본질을 탐구한 것으로 보입니다.

**소스 코드:** [Bat](링크)

**Built with Processing**

> 생성 예술(Generative Art)은 예술가가 직접 모든 픽셀을 그리는 대신, 수학적 규칙이나 알고리즘을 설계하고 컴퓨터가 그 규칙에 따라 작품을 생성하도록 하는 예술 형식입니다. 박쥐의 날개짓 같은 자연 현상을 코드로 구현할 때, 예술가는 날개의 곡선을 베지어 곡선(Bézier curve)으로, 날개짓의 주기를 사인 함수 $\sin(\omega t)$로, 움직임의 무작위성을 펄린 노이즈(Perlin noise) 함수로 표현합니다. 이처럼 수학과 예술의 경계에서 작동하는 생성 예술은, 자연 법칙의 수학적 구조를 시각적으로 드러내는 강력한 도구입니다. Processing은 이러한 실험을 누구나 쉽게 시도할 수 있게 만든 민주적 도구로서, 수학적 사고와 창의적 표현을 연결하는 다리 역할을 합니다.

> 이 문서는 Plus Magazine의 아카이브에서 발췌한 역사적 기록으로, 2000년대 초반 웹 기반 인터랙티브 수학 콘텐츠의 초기 사례를 보여줍니다. 당시에는 Java 애플릿이 웹 브라우저에서 인터랙티브 콘텐츠를 실행하는 주요 기술이었으나, 보안 문제와 모바일 환경의 부상으로 현재는 사실상 사용되지 않습니다. 현대의 동등한 구현은 JavaScript와 WebGL, 또는 p5.js(Processing의 JavaScript 버전)를 사용합니다. 그럼에도 Processing 자체는 여전히 교육과 프로토타이핑에서 활발히 사용되며, 특히 수학적 개념의 시각화와 데이터 아트 분야에서 중요한 도구로 남아 있습니다. 이 작품이 보여주는 "수학적 모델 → 코드 → 시각적 표현"의 흐름은 오늘날 계산적 사고(computational thinking)와 STEAM 교육의 핵심입니다.
